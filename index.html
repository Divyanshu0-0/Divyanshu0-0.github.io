CF-001Built

Blood Cancer Detection

A PyTorch CNN pipeline for cancer detection from histopathology images: a ResNet-50 backbone with attention gates and stain normalization. Grad-CAM makes each prediction visible, so the decision can be checked by eye instead of trusted blindly.

A parallel scikit-learn ensemble on engineered clinical features runs beside it, for comparison with the deep learning approach.

  • PyTorch
  • ResNet-50
  • Attention gates
  • Stain normalization
  • Grad-CAM
  • scikit-learn
CF-002Active

Chest X-Ray Multi-Disease Classifier

A six-week structured build that reads chest X-rays and flags more than one disease at once. It trains on the NIH ChestX-ray14 sample subset in Google Colab. Focal Loss handles the rare findings and Grad-CAM shows where the model looked.

ChestX-ray14 sample → DenseNet-121 → Focal Loss → Grad-CAM → FastAPI + Streamlit

  • DenseNet-121
  • Focal Loss
  • Grad-CAM
  • MLflow
  • Docker
  • FastAPI
  • Streamlit
